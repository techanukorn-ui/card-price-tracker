# Card Price Tracker - SNKRDUNK Auto Update (Chrome Extension)

Extension นี้ทำงานคู่กับเว็บ card-price-tracker: กดปุ่ม "ดึงราคาใหม่" หรือ
"ดึงราคาทั้งหมด" บนเว็บ แล้ว extension จะเปิดแท็บ Chrome จริง ไล่เข้า
SNKRDUNK ทีละการ์ด อ่านราคาขายจริงจากตาราง 売買履歴 คำนวณเฉลี่ยตามกฎเดิม
(3 รายการล่าสุดใน 7 วัน, ถ้าไม่มีก็ใช้รายการล่าสุดสุด) แล้วส่งผลกลับไปบันทึก
ที่เว็บให้อัตโนมัติ — เพราะเป็น Chrome จริงของคุณเอง (ไม่ใช่บอท/headless)
เลยผ่านการเช็คของ Cloudflare ได้เหมือนเปิดเว็บเองปกติ

## อัปเดต (2026-08-17): ใช้เรทค่าเงินคงที่แทนเรทสด

extension ไม่ดึงเรท JPY→THB จาก frankfurter.dev อีกต่อไป — เปลี่ยนไปอ่านเรทที่
ผู้ใช้ตั้งไว้เองจากตาราง `app_settings` แทน (ตั้ง/แก้ได้ที่ปุ่ม "เรทค่าเงิน"
มุมบนของเว็บ) เพราะราคาการ์ดหลายใบไม่ได้เปลี่ยนทุกวัน แต่เรทสดขยับตลอด ทำให้
ตัวเลขบาทดูสั่นทั้งที่พอร์ตไม่ได้เปลี่ยนจริง — ถ้ายังไม่เคยตั้งเรทไว้ extension
จะรายงาน error "ยังไม่ได้ตั้งเรทค่าเงิน" ให้ไปตั้งค่าที่เว็บก่อน

manifest.json เปลี่ยน host_permissions (เอา frankfurter.dev ออก เพิ่ม Supabase
domain) — ต้องกดรีโหลด extension ที่ `chrome://extensions` (ไอคอนวงกลมลูกศร)
หลังอัปเดตโค้ดครั้งนี้ครั้งเดียว

## วิธีติดตั้ง (ทำครั้งเดียว)

1. เปิด `chrome://extensions` ในเบราว์เซอร์
2. เปิดสวิตช์ **โหมดนักพัฒนา (Developer mode)** ที่มุมขวาบน
3. กด **โหลดส่วนขยายที่ยังไม่ได้แพ็ก (Load unpacked)**
4. เลือกโฟลเดอร์นี้ (`browser-extension`) ในโปรเจกต์ card-price-tracker
5. รีเฟรชหน้าเว็บ card-price-tracker แล้วปุ่ม "ดึงราคาใหม่" / "ดึงราคาทั้งหมด" จะใช้งานได้

หมายเหตุ: Chrome จะเตือนว่าเป็น extension ที่ไม่ได้มาจาก Chrome Web Store —
เป็นเรื่องปกติสำหรับ extension ที่เขียนใช้เอง ไม่ต้องกังวล

## วิธีทำงานคร่าวๆ

- `webapp-bridge.js` — ฝังตัวอยู่บนหน้าเว็บ card-price-tracker คอยรับคำสั่ง
  "เริ่มอัปเดตราคา" จากปุ่มบนเว็บ แล้วส่งต่อให้ background, และส่งความคืบหน้า/ผลลัพธ์กลับไปที่เว็บให้ขึ้นเป็นแถบสถานะ
- `background.js` — เปิดแท็บเดียว ไล่ navigate ไปทีละการ์ด, รอโหลด, กดปุ่ม
  กรองเกรด/สภาพให้ตรงกับการ์ดใบนั้นบนหน้า SNKRDUNK, อ่านตารางประวัติขาย,
  คำนวณราคาเฉลี่ย, ดึงอัตราแลกเปลี่ยน JPY→THB ล่าสุด แล้ว POST ไปที่
  `/api/update-price` ของเว็บ

## ข้อจำกัดที่รู้อยู่แล้ว

- ถ้าการ์ดใบไหนใช้เกรดที่ไม่ตรงกับปุ่มกรองบนหน้า SNKRDUNK พอดี (เช่นบางเกรด
  ที่ SNKRDUNK รวมเป็นบัคเก็ตเดียว อย่าง "PSA8以下") extension จะรายงานว่า
  ล้มเหลวแทนที่จะเดาสุ่ม — ต้องอัปเดตการ์ดใบนั้นด้วยตัวเองหรือขอให้ Claude ช่วย
- ถ้าเปิดหลายการ์ดรัวๆ ในโหมด "ดึงราคาทั้งหมด" มีดีเลย์ระหว่างใบอยู่แล้ว
  (~1.8 วินาที) เพื่อไม่ให้ดูเป็นการยิงคำขอถี่ผิดปกติ

## เวอร์ชัน iPhone / iOS Safari (`ios-userscript.user.js`)

Extension ข้างบนเป็น Chrome extension ใช้บน iOS Safari ไม่ได้ (iOS ไม่มี
background script/tabs API แบบ Chrome) เลยมีสคริปต์แยกสำหรับมือถือ ทำงานคนละ
แบบ: แทนที่จะเปิดแท็บใหม่ทีละใบ (ซึ่ง iOS Safari บล็อก popup ที่ไม่ได้เกิดจาก
การแตะโดยตรง) จะเปิดแท็บ SNKRDUNK **แค่ใบเดียว** แล้วให้สคริปต์สั่ง
`location.href` เปลี่ยนหน้าไปการ์ดใบถัดไปเองในแท็บเดิมไปเรื่อยๆ จนครบ
คิวทั้งหมดถูกฝังมาในพารามิเตอร์ของ URL ตั้งแต่ตอนกดปุ่ม "อัปเดตราคา (มือถือ)"
บนเว็บ ไม่มีการเก็บ state ไว้ที่ไหนอีก

วิธีติดตั้ง: ดูคำแนะนำแบบละเอียดที่ผู้ใช้ได้รับตรงจาก Claude ตอนเพิ่มฟีเจอร์นี้
(ติดตั้งแอป "Userscripts" จาก App Store, เปิดเป็น Safari Extension ใน
Settings → Apps → Safari → Extensions, แล้ววางเนื้อหาไฟล์นี้เป็นสคริปต์ใหม่)
